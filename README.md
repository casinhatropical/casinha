# Casinha Tropical

Site institucional do hostel Casinha Tropical (Tijuca, Rio de Janeiro).

## Deploy

Este repositório está conectado ao [Vercel](https://vercel.com). Cada push na branch `main` gera um deploy automático.

- **Domínio:** https://casinhatropical.com
- **Preview:** cada PR/commit recebe uma URL de preview

## Editar o site

O site é um único arquivo estático:

- `index.html` — HTML, CSS e JavaScript do site completo

Edite `index.html`, faça commit e push. O Vercel publica em alguns segundos.

## Desenvolvimento local

Abra `index.html` no navegador ou use um servidor local:

```bash
npx serve .
```
